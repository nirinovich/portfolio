SmartService is an emergency alert application that allows users to quickly contact the nearest authorities in case of danger.

## Context

Built during the Inter-University Hackathon organized by Techzara (April 2025). The project was presented to over 100 people, including jury members.

## Features

- Emergency alert system
- Geolocation-based authority matching
- Quick contact interface
- React-based web application

## Role

Frontend developer — built the web interface with React and presented the project to the jury.

Astro is a modern web framework designed for building fast, content-driven websites. It ships zero JavaScript by default, making it incredibly performant.

## Why Astro?

- **Zero JS by default** — Only the JavaScript you explicitly need
- **Content collections** — Type-safe content management
- **Islands architecture** — Interactive components where you need them
- **Built-in i18n** — First-class internationalization support

## Getting Started

```bash
npm create astro@latest
```

Astro's file-based routing makes it easy to create pages. Just drop a `.astro` file in `src/pages/` and you have a new route.

# ADR-013: Engineering Philosophy Copy

**Status:** Accepted
**Date:** 2026-08-03

## Context

The manifesto section previously used copy borrowed from Matt Pocock ("Engineering fundamentals are your biggest advantage" + 4 paragraphs). This is not original and does not reflect the user's actual philosophy.

## Decision

Replace with the user's own philosophy:
- Values-first approach
- Result-driven engineering
- AI will still need someone to manage it
- Bad code debt exists and must be managed

The copy should be written in the user's voice, not generic engineering platitudes.

## Consequences

- Original, authentic messaging
- Differentiates from other developer portfolios
- Copy needs to be drafted and reviewed by the user

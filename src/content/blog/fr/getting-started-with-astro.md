Astro est un framework web moderne conçu pour construire des sites web rapides et orientés contenu. Il envoie zéro JavaScript par défaut, ce qui le rend extrêmement performant.

## Pourquoi Astro ?

- **Zéro JS par défaut** — Uniquement le JavaScript dont vous avez réellement besoin
- **Content collections** — Gestion de contenu typée et sécurisée
- **Architecture en îles** — Des composants interactifs là où vous en avez besoin
- **i18n intégré** — Un support d'internationalisation de premier ordre

## Pour commencer

```bash
npm create astro@latest
```

Le routage basé sur les fichiers d'Astro facilite la création de pages. Il suffit de déposer un fichier `.astro` dans `src/pages/` pour avoir une nouvelle route.

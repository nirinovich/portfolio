This portfolio website showcases my work and projects. Built with modern web technologies, it features smooth GSAP animations, responsive design, and full internationalization support.

## Features

- Full-screen hero with stagger entrance animations
- Scroll-revealed sections using GSAP ScrollTrigger
- French and English language support
- Content collections for type-safe project and blog data
- Responsive design with Tailwind CSS

## Tech Stack

- **Astro 7** — Static site generation with islands architecture
- **Tailwind CSS 4** — Utility-first styling
- **GSAP** — High-performance animations
- **TypeScript** — Type safety throughout

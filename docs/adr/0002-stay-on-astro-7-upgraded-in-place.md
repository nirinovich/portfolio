# Stay on Astro 7 + Tailwind 4, upgraded in place

We considered switching to a React meta-framework (Next.js / Remix) for the overhaul, but are keeping the current stack — Astro 7 + Tailwind 4 (via `@tailwindcss/vite`) + GSAP + astro-icon — and upgrading within it (View Transitions, Content Layer collections, icon sprite). The stack is already current; a full overhaul is achievable without a risky migration, and the frozen hero's GSAP animations are preserved as-is.

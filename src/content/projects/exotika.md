Exotika.mg is a complete e-commerce website for a vape shop based in Madagascar.

## Features

- Product catalog with CMS integration (Contentful)
- Responsive design for mobile and desktop
- Deployed on Firebase Hosting
- Content management via Contentful CMS

## Role

Solo developer — built the entire frontend in React, integrated Contentful for content management, and deployed on Firebase.
